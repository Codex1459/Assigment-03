# Java Arrays Lab Practice

This repository contains solutions to Java array practice problems from Level 1 to Level 3.

---

## Programs Included

###  Level 1
- Voting eligibility check
- Positive/Negative/Zero & Even/Odd check
- Multiplication table

###  Level 2
- Employee bonus calculation
- Youngest and tallest friend finder

###  Level 3
- Digit frequency counter

---

## Files

All programs are stored in a single directory:
- VotingCheck.java
- NumberCheck.java
- MultiplicationTable.java
- EmployeeBonus.java
- Friends.java
- DigitFrequency.java

---

##  Technologies Used
- Java
- Arrays
- Loops
- Conditional Statements

---

##  How to Run

1. Compile a file:
```bash
javac FileName.java
```
2. Run the program:
```bash
java FileName
```
